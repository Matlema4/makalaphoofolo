## 🚀 Getting Started

No installation or build step needed. Just open the HTML file in a browser:

```bash
# Clone the repository
git clone https://github.com/your-username/makalaphoofolo.git

# Open in browser
open makalaphoofolo.html
```

Or simply double-click `makalaphoofolo.html` to open it locally.

> **Note:** Ensure `makala_logo.png` and `otherlogos.png` are in the same folder as the HTML file so images load correctly.
